Privacy policy

Last updated: September 30, 2026

RL Uploader is a personal tool that runs on its owner's own computer. It uploads Rocket League gameplay videos to the owner's YouTube channel.

What the app accesses

When signed in, the app uses the YouTube Data API with the permission to manage YouTube videos (youtube.upload). It uses this only to upload videos, set their titles, descriptions, tags and privacy, and set their thumbnails on the signed-in user's own channel.

What the app stores

The sign-in token issued by Google is stored only on the owner's computer, so that uploads can run without signing in each time. The app does not send any data to its own servers (it has none), and it does not sell, share or transfer any data to third parties. Videos are sent only to YouTube.

Other people's data

The app does not collect personal data from anyone. Player names shown in videos come from the public Rocket League replay files being recorded.

Google API Services

RL Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends the app's access.
